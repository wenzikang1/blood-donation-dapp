## 💡 常见问题

### Q1: DOI年份和出版年份不一样，是错误吗？
**A**: 不是！这是正常现象。
- 例如：DOI可能是 `2023.109892`，但文章在2024年正式出版
- 原因：文章先在线发布（获得DOI），后正式出版

### Q2: "查不到"是什么意思？
**A**: 意思是：
- DOI格式本身是正确的
- 但我无法确认文章的详细信息（标题、作者）是否完全匹配
- **不代表文献一定有问题**，只是需要您重新确认

### Q3: 如何处理"查不到"的文献？
**A**: 三个选择：
1. 用DOI直接访问文章，确认信息
2. 在原始数据库（Web of Science, Scopus等）重新查找
3. 如果确实找不到，使用其他相似文献替代
